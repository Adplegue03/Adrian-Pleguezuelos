# CLUBS XI — Champions Histórica

## Catálogo importado
- 71 temporadas campeonas desde 1955-56 hasta 2025-26.
- Plantillas, posiciones y medias importadas de `Plantillas.docx` aportado por el usuario.
- Cada registro se conserva ligado a su club y temporada.
- Las versiones de un mismo futbolista se bloquean por identidad normalizada en el draft.

## Ejecutar
Abre `index.html` en un navegador. No requiere instalación ni servidor para la demo local.

## Notas
Esta versión es un prototipo estático. Supabase, Google OAuth y Cloudflare Pages aún no están conectados.
